# IndexNow Yandex — описание и установка

## 📖 О программе

**IndexNow Yandex** — портативная десктопная утилита для Windows, которая позволяет отправлять URL-адреса вашего сайта на переиндексацию поисковым роботом Яндекса через протокол **IndexNow**.

Программа принимает список ссылок, проверяет их на корректность, отсеивает дубликаты и мусор, а затем одним или несколькими пакетами отправляет их в API Яндекса. Результат отправки и подробная статистика отображаются прямо в окне.

### Что умеет

| Возможность | Описание |
|---|---|
| **Массовая отправка** | До 10 000 URL за один запрос, автоматическая разбивка на пакеты при большем объёме |
| **Валидация URL** | Проверка схемы (`http`/`https`), хоста, порта; отклонение мусора до отправки |
| **Автоопределение домена** | Если поле «Домен» пустое, хост берётся из первой ссылки |
| **Дедупликация** | Удаление повторов с учётом регистра схемы и хоста, но с сохранением регистра пути |
| **Поддержка IDN** | Кириллические домены (`.рф`, умляуты) автоматически конвертируются в Punycode |
| **Percent-encoding** | Пути и query-параметры с кириллицей кодируются по RFC 3986 |
| **Строгое сравнение хостов** | `example.com` ≠ `www.example.com`, `http://` ≠ `https://` |
| **Смешанные схемы** | Если в списке есть и `http://`, и `https://` — отправка идёт двумя запросами |
| **keyLocation** | Автодополнение относительного пути до полного URL, проверка совпадения хоста и схемы |
| **Статистика** | Отправлено / отклонено с разбивкой по причинам (дубликаты, некорректные, чужой домен, другая схема) |
| **Прогресс** | Индикатор выполнения по числу отправленных пакетов |
| **Автоматические retry** | Повторная попытка при `429` и `5xx` с экспоненциальной задержкой (2/4/8 с) |
| **Устойчивость** | Потокобезопасный UI, корректное завершение без зависаний в диспетчере задач |

### Что нужно перед запуском

1. **Ключ IndexNow** — строка длиной 8–128 символов, состоящая из `[A-Za-z0-9_-]`.
2. **Файл с ключом на сайте** — разместите его по адресу вида `https://ваш-сайт.ru/ваш-ключ.txt`. Содержимое файла — только сам ключ, без разметки и пробелов. Это подтверждает Яндексу, что вы владелец сайта.
3. **Windows** (или любая ОС с Python 3.9+), для сборки `.exe` — Windows.

> ⚠️ IndexNow не гарантирует индексацию — он только уведомляет поискового робота о наличии или изменении страницы.

## 🖥️ Интерфейс

### Поля ввода

| Поле | Обязательное | Описание |
|---|---|---|
| **Домен (host)** | Нет | Хост сайта без схемы и пути (`example.com`). Если пусто или `example.com` — будет подставлен из первой ссылки |
| **Ключ IndexNow** | Да | 8–128 символов `[A-Za-z0-9_-]` |
| **keyLocation** | Нет | Полный URL файла с ключом. Можно указать относительный путь — программа дополнит хостом и схемой |
| **Ссылки** | Да | По одной на строку. До 10 000 в одном запросе, больше — автоматически разбивается на пакеты |

### Горячие клавиши

- `Ctrl+A` — выделить всё в активном поле
- `Cmd+A` — то же для macOS

## 🚀 Установка с исходников

### Шаг 1. Установите Python

Скачайте Python 3.9 или новее с [python.org/downloads](https://www.python.org/downloads/windows/).

> ⚠️ При установке обязательно отметьте галочку **«Add Python to PATH»**.

Проверьте установку:

```powershell
python --version
pip --version
```

Оба должны вывести версии без ошибок. Если команды не найдены — Python не добавлен в `PATH`, переустановите с нужной галочкой.

### Шаг 2. Скачайте проект

Скопируйте папку `IndexNowApp` в удобное место, например `E:\IndexNowApp`.

Проверьте, что структура такая:

```powershell
cd E:\IndexNowApp
dir
```

Должны быть видны `run.py` и папка `indexnow_app`.

### Шаг 3. Установите зависимости

```powershell
python -m pip install --upgrade pip
python -m pip install requests
```

Для сборки `.exe` дополнительно:

```powershell
python -m pip install pyinstaller
```

> `python -m pip` предпочтительнее `pip`, потому что гарантированно использует тот же интерпретатор, что и `python`.

### Шаг 4. Запустите программу

```powershell
python run.py
```

Альтернативный способ:

```powershell
python -m indexnow_app
```

Откроется окно программы.

## 📦 Сборка портативного `.exe`

### Обычная сборка

```powershell
cd E:\IndexNowApp
python -m PyInstaller --onefile --windowed --name "IndexNow_Yandex" run.py
```

- `--onefile` — единый `.exe`, без DLL-россыпи
- `--windowed` — без консольного окна
- `--name` — имя выходного файла

### Результат

```
E:\IndexNowApp\
├── build\                       (временные файлы — можно удалить)
├── dist\
│   └── IndexNow_Yandex.exe      ← портативный файл
├── IndexNow_Yandex.spec
├── run.py
└── indexnow_app\
```

Готовый файл `dist\IndexNow_Yandex.exe` можно скопировать на любой компьютер с Windows. Python на целевой машине **не требуется**.

### Отладочная сборка

Если `.exe` падает или не запускается — соберите с консолью, чтобы увидеть traceback:

```powershell
python -m PyInstaller --onefile --name "IndexNow_Yandex_Debug" run.py
.\dist\IndexNow_Yandex_Debug.exe
```

После диагностики пересоберите с `--windowed`.

### Если `pyinstaller` не распознаётся

Команда `pyinstaller` может быть не в `PATH`, даже если пакет установлен. Всегда работает запуск через модуль:

```powershell
python -m PyInstaller --version
python -m PyInstaller --onefile --windowed --name "IndexNow_Yandex" run.py
```

Если это помогло, но хочется использовать просто `pyinstaller`, добавьте в `PATH` папку со скриптами Python:

```powershell
python -c "import sysconfig; print(sysconfig.get_path('scripts'))"
```

Вывод — путь вида `C:\Users\ВашеИмя\AppData\Local\Programs\Python\Python312\Scripts`. Добавьте его в переменную среды `Path` через «Параметры системы → Переменные среды».

## 🧪 Быстрая проверка работоспособности

1. Откройте программу.
2. В поле **Домен** оставьте `example.com` — он будет заменён автоматически.
3. В поле **Ключ** введите тестовый ключ, например `test-key-123456`.
4. В поле **Ссылки** вставьте:
   ```
   https://example.com/page1
   https://example.com/page1
   https://example.com/page2
   https://other-site.com/page
   просто_текст
   ```
5. Нажмите **Отправить в Яндекс**.

Программа должна показать в логе:

```
============================================================
Домен определён автоматически: example.com
Статистика по введённым данным:
   Всего строк в поле ввода: 5
   К отправке:               2
   Отклонено:                3
      - дубликаты:           1
      - некорректные URL:    1
      - чужой домен:         1
Отправка 2 URL на example.com...
HTTP-код ответа: 403. Неверный ключ. Проверьте ключ и его расположение.
```

Код `403` в этом примере ожидаем — ключ `test-key-123456` не опубликован на сайте. Это доказывает, что программа работает: данные ушли на сервер, ответ пришёл, интерфейс отреагировал.

## 🔑 Как получить рабочий ключ и настроить сайт

1. Придумайте ключ: 8–128 символов из `[A-Za-z0-9_-]`. Пример: `a1b2c3d4-e5f6-7890`.
2. Создайте на сайте файл, например `https://example.com/a1b2c3d4-e5f6-7890.txt`.
3. Содержимое файла — **только сам ключ**, без HTML, без кавычек, без переводов строки в начале:
   ```
   a1b2c3d4-e5f6-7890
   ```
4. Убедитесь, что файл доступен по HTTPS и отдаётся с кодом `200`.
5. В программе укажите:
   - **Домен**: `example.com`
   - **Ключ**: `a1b2c3d4-e5f6-7890`
   - **keyLocation**: `https://example.com/a1b2c3d4-e5f6-7890.txt`

После этого запросы будут приниматься с кодом `200` или `202`.

## ❓ Частые вопросы

**Какой код ответа считается успешным?**
- `200 OK` — страницы приняты на переиндексацию.
- `202 Accepted` — ключ принят и ожидает проверки, отправьте ещё несколько адресов в течение суток.

**Почему ссылки с `www.` отклоняются, если домен введён без `www.`?**
Это осознанное поведение: `example.com` и `www.example.com` — технически разные хосты. Вводите домен ровно в той форме, в которой он фигурирует в ссылках.

**Почему часть ссылок `http://`, а часть `https://` — они не отправятся вместе?**
IndexNow требует единый протокол для `keyLocation` и списка URL. Программа автоматически отправляет две группы отдельными запросами: сначала все `http://`, затем все `https://`. Если `keyLocation` был введён явно (со схемой), он не переписывается; если относительный — получает схему группы.

**Как часто можно отправлять одни и те же URL?**
Рекомендуется не чаще, чем раз в 10 минут. При превышении лимитов сервер возвращает `429`, и программа автоматически повторит запрос с задержкой 2/4/8 секунд.

**Что делать, если `.exe` не запускается на другом компьютере?**
Убедитесь, что это Windows 7 SP1+ (64-бит) и установлены обновления Microsoft Visual C++ Redistributable (обычно уже есть). Соберите отладочную версию с консолью, чтобы увидеть точную причину.

**Где хранятся ключ и домен между запусками?**
Программа не сохраняет данные — при закрытии всё стирается. Это сознательное решение в пользу простоты и безопасности. Если нужно — храните ключ в текстовом файле и копируйте оттуда.

## ⚙️ Технические детали

- **Язык**: Python 3.9+
- **GUI**: Tkinter (входит в стандартную поставку Python для Windows)
- **HTTP**: `requests` + `urllib3.Retry` (retry на 429, 500, 502, 503, 504)
- **Многопоточность**: фоновый `threading.Thread` (daemon), обмен с UI через `queue.Queue` и `root.after`
- **Стандарты**: URL-кодирование по RFC 3986, IDN по RFC 5890, спецификация IndexNow 1.0
- **Лицензия**: используйте свободно на свой страх и риск

---

## 📋 Ограничения

- Не гарантирует индексацию — только уведомляет робота Яндекса.
- Не работает с авторизацией в URL (`user:pass@host`) — это не приветствуется IndexNow.
- Не сохраняет историю отправок между запусками.
- Не проверяет существование страниц — только формат URL.
- Порт в URL не поддерживается: если в ссылке `example.com:8080`, она отклоняется, поскольку IndexNow работает только с hostname без порта.
